PluginLoader

class PluginLoader(hostClassLoader: ClassLoader = PluginLoader::class.java.classLoader, sdkWhitelist: List<SdkWhitelistEntry> = emptyList())

Creates isolated PluginClassLoaders for scanned plugin candidates.

Deliberately unaware of org.pcsoft.framework.pluggiat.scanner.PluginScanResult or any other scanner/security type - it only needs a candidate's own Path (single JAR, own folder, or ZIP file, auto-detected) and its already-parsed PluginManifest. It performs no security check of its own and is unconditionally callable regardless of any prior security outcome - deciding whether loading a given plugin is warranted, and logging that decision, is entirely up to the caller.
