PluginClassLoader

class PluginClassLoader(urls: Array<URL>, hostClassLoader: ClassLoader, sdkWhitelist: List<SdkWhitelistEntry>, dependencyClassLoaders: List<PluginClassLoader>) : URLClassLoader

Isolated, parent-last class loader for a single loaded plugin.

Class resolution order: platform classes (java.*/javax.*, always delegated to the JDK platform class loader regardless of sdkWhitelist), then sdkWhitelist-matched classes delegated to hostClassLoader, then the plugin's own JARs (urls), then dependencyClassLoaders in declaration order. A plugin can therefore never see host-internal classes outside the whitelist, and never sees another plugin's classes unless that plugin's class loader was explicitly passed in as a dependency.

Parameters

urls

the plugin's own JAR(s) to load classes/resources from
